# Guide

Welcome to the nPlyr User Guide. nPlyr is a native video player for macOS and iOS with a
built-in media sniffer and a hikerView-compatible mini-program runtime.

Start here:

- [Introduction](/guide/introduction) — what nPlyr is and its system requirements.
- [Installation](/guide/installation) — install on macOS or iOS / iPadOS.
- [Player](/guide/player) — controls and gestures.
- [Browser & Sniffer](/guide/browser) — capture direct links from the web.
- [Downloads & Library](/guide/downloads) — save streams and organize media.
- [Settings](/guide/settings) — themes, language, preferences.
- [Mini-Programs](/guide/miniapps) — run community rules, and the
  [Compatibility](/guide/miniapp-compatibility) boundary.
- [Permissions](/guide/permissions), [Troubleshooting](/guide/troubleshooting),
  [FAQ](/guide/faq).
