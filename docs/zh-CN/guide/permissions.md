# 权限

nPlyr 刻意**精简权限**。因为它是一个媒体播放器（而非剪贴板或录屏工具），它**不**请求辅助功能或屏幕录制权限。唯一可能出现的权限，是任何需要网络与文件的应用都需要的那些标准权限。

## 网络访问

流媒体、嗅探与小程序源都需要出站网络访问。在 macOS 上，App Store 沙盒默认允许——**不会有任何提示**，也无需手动授权。

## 文件与文件夹

- **打开本地文件**使用标准的 macOS 打开面板，因此由你自己挑选文件；不需要任何整体文件夹访问权限。
- **保存下载**会写入你的**下载**文件夹（或你选择的文件夹）。首次下载时，macOS 可能会弹出沙盒提示以确认位置。授权一次，nPlyr 就会记住该选择。

如果之后移动了 nPlyr 的数据或撤销了访问，你可以在**系统设置 → 隐私与安全性 → 文件与文件夹**中重新授权。

## 通知（可选）

下载完成时，nPlyr 可能会显示一个本地通知。这是可选的，可在**系统设置 → 通知 → nPlyr** 中关闭。

## nPlyr 不请求什么

| 权限 | 是否需要 | 原因 |
|---|---|---|
| 辅助功能 | 否 | 键盘快捷键使用应用内事件监视器，而非全局辅助功能控制。 |
| 屏幕录制 | 否 | nPlyr 播放并抓取*网络*媒体；它从不录制你的屏幕。 |
| 完全磁盘访问 | 否 | 所有文件访问都经由打开/保存面板或下载文件夹进行。 |
| 相机 / 麦克风 | 否 | nPlyr 是一个观看工具；它不捕获输入设备。 |

如果你看到此处未列出的权限提示，几乎可以肯定来自某个小程序或浏览器访问的特定站点——而非核心应用。如果看起来有什么不对，请参阅[故障排查](/zh-CN/guide/troubleshooting)。
