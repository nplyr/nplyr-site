# 隐私选择

nPlyr 是一款本地优先的应用。由于你的数据留在你的设备上，我们不会收集、出售或共享任何个人信息。

## 我们本地保存的数据

nPlyr 将所有数据本地保存在你的设备上：

- 观看历史、书签与下载内容
- 应用偏好与主题
- 小程序变量（仅在本地存储中，且仅来自你导入的规则）
- 调试日志（若启用）

这些数据都不会被应用本身上传到任何服务器。

## 网络由用户主导

nPlyr 仅在流媒体、下载、浏览或运行你选择的某个小程序时使用网络。没有云端 AI 功能，也没有账号，因此没有需要选择加入或退出的事项——应用根本不会把你的数据发送给我们。

## 你的权利

由于 nPlyr 不在我们的服务器上收集或存储个人数据，也就没有可供我们访问、删除或转移的个人数据。你所有的数据都可以在应用内直接管理，或通过移除应用的容器文件夹来管理：

```bash
rm -rf ~/Library/Containers/com.w3cub.nPlyr
```

## 不出售

nPlyr 不出售任何个人信息。我们不使用任何第三方的分析、广告或追踪服务。
