# 小程序资源

本页属于**小程序**指南章节——即 nPlyr 可以导入的社区小程序与规则源目录。nPlyr **不**随附固定的视频源列表；相反，源由你自行提供，应用内的管理器负责导入。

## 资源来自哪里

- **hikerView 生态。** nPlyr 与 Android 应用所用的同一批分享文本和 JSON 兼容，因此现有社区规则可直接导入。
- **云分享。** nPlyr 支持云后端 **TextDB**（云2）、`cmd.im`（302 重定向，云5）与 **pasteme**（云6），因此托管在那里的规则可以一步订阅。
- **你自己的。** 编写或改编一条规则并导入——请先参阅[小程序概览](/zh-CN/guide/miniapps)与[兼容性](/zh-CN/guide/miniapp-compatibility)边界。

## 添加资源

1. 在 nPlyr 中打开**小程序**（macOS 上是管理器窗口，iOS 上是一个页面）。
2. 选择**添加**，粘贴分享文本 / JSON，或选择一个云源进行订阅。
3. 该程序会出现在首页顶行——拖拽以重排。

免费层级限制你一次可保留的导入程序数量；一次性解锁会移除该限制。

## 兼容性是关键

并非每一条 Android 规则都在 nPlyr 上完全一致地运行。nPlyr 的引擎是 **JavaScriptCore**，而非 Java/Rhino，并且只模拟了经过筛选的 Java API 子集。在依赖某个源之前，请查阅[兼容性](/zh-CN/guide/miniapp-compatibility)页面，并报告任何失败的规则（附上规则名称及其失败的步骤）。

> 你在此浏览的目录由社区维护。nPlyr 并非第三方小程序的作者，也不为其内容背书——只安装你信任的源。
