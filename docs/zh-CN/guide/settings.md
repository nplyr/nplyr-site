# 设置

nPlyr 的设置窗口按标签页组织。本页带你了解大多数人最先更改的若干项。

## 外观与语言

### 主题

nPlyr 内置多个主题，每个都以一个标志性的强调色为基调。切换主题时，整个界面——包括每一个打开的窗口——都会立即更新。你也可以自动**跟随系统外观**（浅色 / 深色）。

### 语言

界面已本地化为 **25 种语言**。更改语言会在所有已打开窗口与菜单栏上立即生效——无需重启。（这一实时切换是通过在语言变化时重建每个窗口的视图来实现的。）

## 通用

- **浏览器 user-agent**——选择 *自动*、*移动端*、*桌面端（PC）*，或粘贴一个**自定义** UA。该 UA 由[嗅探器](/zh-CN/guide/browser)以及播放/解析在需要时采用。规则也可以指定自己的 UA；只有当选择跟随规则的值时，齿轮设置才会覆盖它。
- **文件关联**——让 nPlyr 在你在 Finder 中双击本地音视频文件（`.mp4`、`.mkv`、`.mov`、`.m4v`、`.webm`、`.flv`、`.mka` 等）时打开它们。

## 下载

- 已下载媒体的默认保存位置。
- 是否提供**边下边播**。
- 清晰度默认值，以及是否自动下载字幕。

## 播放器

- 默认播放速度。
- 手势偏好（触控板 / 触摸灵敏度）。
- 画中画与 AirPlay 默认值。

## 去广告

订阅 Chrome 兼容的过滤列表。nPlyr 会在浏览器中以及播放期间过滤请求。去广告与边下边播互斥。

## 小程序

管理已导入的小程序与规则源：添加、编辑、重排与删除。**免费层级**会限制小程序的数量；解锁后移除该限制，以一次性购买形式存储。参见[小程序](/zh-CN/guide/miniapps)。
