# 浏览器与嗅探器

nPlyr 内置一个基于 `WKWebView` 的真正的**多标签浏览器**，并带有**媒体嗅探器**。当你遇到一个不主动提供直链的页面时，它就是用来抓取直链的工具。

## 浏览器

这是一个 Chrome 风格的标签浏览器：

- **标签**——新建 / 关闭 / 切换 / 重排；将标签拖出可成为独立窗口（macOS）。
- **导航**——后退、前进、刷新，以及带自动补全的地址栏。
- **键盘快捷键**——`⌘T` 新建标签、`⌘R` 刷新、`⌘[` / `⌘]` 后退 / 前进、`⌘L` 聚焦地址栏。
- **拖放**——将 URL 或文本拖入窗口即可打开。
- **弹窗**——`target="_blank"` 与 `window.open` 会在新标签中打开，而不是被拦截。
- **对话框**——JS 的 `alert` / `confirm` / `prompt` 以原生方式呈现。
- **下载**——被拦截的下载链接会在应用内**下载**标签（`nplyr://downloads`）中打开。

## 嗅探器的工作原理

页面加载时，nPlyr 会注入一个脚本，挂钩：

- `fetch` 与 `XMLHttpRequest`，
- `video.src` 与 `HTMLMediaElement` 播放，
- `MediaSource` / `SourceBuffer.appendBuffer`。

它还会通过 `WKNavigationDelegate` 监视导航，以捕获服务端媒体重定向。任何看起来像媒体文件的内容——**m3u8 / mp4 / flv / ts**——都会连同其**请求头**（referer、user-agent、cookie、auth）一起被收集到结果抽屉中。

在抽屉中你可以：

- 立即在[播放器](/zh-CN/guide/player)中**播放**该链接。
- 通过[下载](/zh-CN/guide/downloads)将其**下载**（保留请求头）。
- **复制** URL 与请求头，以便在其他地方使用。

> 嗅探器只捕获页面实际请求的链接。使用专有播放器或重度 DRM 包裹视频流的站点可能不会暴露干净的直链——对于这类源，一个了解该源 API 的[小程序](/zh-CN/guide/miniapps)是更可靠的路径。

## 已知限制

以下项目是有意降低优先级，可能在后续版本中提供：

- 页内右键菜单项（"在新标签打开链接"、"下载链接"）——macOS 的 `WKUIDelegate` 右键菜单钩子是 iOS 专属的；nPlyr 目前依赖标签栏与工具栏。
- 页内**查找**（`⌘F`）——WebKit API 存在，但 UI 尚未接好。
- **打印**（`⌘P`）——WebKit 支持，但尚无菜单项。
- `⌘W` 在多个标签打开时会关闭整个窗口；按标签关闭正在规划中。
- 全面重启应用后，已打开的标签与历史**不会**恢复。

## 隐私

该浏览器是一个标准的 `WKWebView`。它不会注入自身的追踪器。Cookie 与本地存储都留在应用的容器内。完整说明请参阅[隐私](/zh-CN/guide/privacy)。
