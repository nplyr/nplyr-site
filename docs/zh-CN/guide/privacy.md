# 隐私政策

nPlyr 是一款面向 macOS 与 iOS 的原生视频播放器。你的隐私是我们的首要任务。

## 本地优先设计

- 你的观看历史、书签与下载内容**完全存储在你自己的设备上**。
- 应用**不需要账号，也不需要注册**。
- **没有遥测**——nPlyr 不会将使用数据回传。
- 一旦媒体已在你的设备上，核心播放与下载功能可完全离线工作。

## 网络使用由用户主导

nPlyr 只在*你*要求时才使用网络：

- 流式播放或下载你打开或抓取的视频。
- 使用内置嗅探器浏览。
- 运行你导入的小程序 / 规则源。

我们不运营接收你的媒体、历史或小程序变量的服务器。

## 浏览器

内置浏览器是一个标准的 `WKWebView`。它不会注入自身的追踪器。Cookie 与本地存储都留在应用的容器内，与其他任何浏览器一样。

## 小程序数据

小程序是社区提供的规则，运行在沙盒化的 JavaScript 引擎中。规则存储的任何变量（`setItem` / `getItem`）都保存在你设备上的应用本地存储中。nPlyr 不会读取或传输它们。

## 调试日志

如果你启用了调试日志，日志会被写入本地，并且只有在*你*选择导出它们以报告问题时才会被分享。

## 你的选择

- 随时删除单个历史 / 书签 / 下载条目。
- 从**设置 → 高级 → 重置**重置所有本地数据。
- 从**小程序**管理器中移除一个小程序及其存储的变量。

nPlyr 的设计默认就是私密的——没有什么需要"退出"。
