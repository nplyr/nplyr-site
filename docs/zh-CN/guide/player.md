# 播放器

nPlyr 的播放器是一套由 `AVPlayer` 驱动、macOS 与 iOS 共用的内核。本页介绍日常控件与平台专属手势。

## 打开内容

从主屏幕你可以：

- **打开文件**——将本地视频拖入窗口，或使用文件选择器。
- **打开 URL**——将直链（`.mp4`、`.m3u8`、`.flv`、`.ts` 等）粘贴到 URL 输入框。
- **从嗅探器打开**——将抓取的链接从[浏览器](/zh-CN/guide/browser)抽屉直接发送给播放器。
- **从小程序打开**——点击可播放的条目，nPlyr 会通过[规则引擎](/zh-CN/guide/miniapps)解析它。

## 常用控件（双平台通用）

| 控件 | 作用 |
|---|---|
| 播放 / 暂停 | 空格键（macOS）或轻点视频中心（iOS） |
| 进度 | 拖动进度条，或使用下方平台手势 |
| 音量 | 系统 / 屏幕音量 |
| 倍速 | 通过倍速按钮在 0.5×–3× 之间调整 |
| 音轨 | 当源包含多音轨时可选择 |
| 字幕 | 加载外部 `.srt` / `.vtt`，或使用内嵌音轨 |
| 画中画 | 将视频弹出为悬浮的画中画窗口 |
| AirPlay | 将视频发送到 Apple TV 或 AirPlay 扬声器 |
| DLNA（macOS） | 投放到局域网中的 DLNA 设备 |

## macOS 手势与快捷键

### 触控板

- **横向滑动**拖动时间线。拖动时**预览**新位置；当你抬起手指（或停顿 250 毫秒）时才真正跳转，因此误滑绝不会让视频乱跳。
- **纵向滑动**根据起始位置调整**亮度**或**音量**：视频**左半侧**控制亮度，**右半侧**控制音量。第一次滑动会锁定轴向，二者互不干扰。
- **滚轮**悬停在进度条上时可微调位置（每格 ±5%）。

### 亮度

macOS 不提供公开 API 来调暗其他应用的视频，因此 nPlyr 在视频与控件之间叠加一层调暗层。这只是视觉上的处理——底层画面本身并未改变。

### 键盘快捷键

快捷键仅按**修饰键**（`⌘`、`⌥`、`⌃`、`⇧`）匹配——方向键与小键盘不参与匹配，因此方向键绑定始终可靠。在文本框（URL 栏、搜索框等）中输入时，单键快捷键会被抑制。

如果某个快捷键突然失效，请参阅[故障排查](/zh-CN/guide/troubleshooting)。

## iOS 手势

- **双击**将屏幕分为三个区域：轻点**左三分之一**后退 10 秒，**右三分之一**前进 10 秒，**中间**播放 / 暂停（并在点击处显示涟漪）。
- **长按（0.5 秒）**临时以 **2.0×** 播放；松开后恢复普通速度。
- 边缘**死区**（约 30 pt，或短边的 10%）被忽略，因此从屏幕边缘开始滑动不会误触手势。该死区仅在全屏时生效。

## 高级播放

### 多线路视频 JSON

某些规则会返回一个结构化 JSON，描述多条视频线路（不同分辨率或 CDN）、字幕、歌词与音频 URL。nPlyr 将其解析为一个**线路切换器**，让你在不丢失进度的情况下切换线路。

### 续播与换源

- nPlyr 会记住你停在哪里，并在下次提供**续播**选项。
- 在播放中途切换源时，交换瞬间会**冻结最后一帧**，以免屏幕闪黑。
- 在条目就绪之前发出的跳转会被**排队**，并在播放可以开始的瞬间立即应用——因此你永远不会在不知情的情况下从头重播。

### 边下边播

你可以在文件仍在下载时就开始观看。参见[下载与媒体库](/zh-CN/guide/downloads)。
