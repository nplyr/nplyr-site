# 常见问题

**问：nPlyr 是什么？**

答：nPlyr 是一款面向 macOS 与 iOS/iPadOS 的原生视频播放器。它可以播放本地文件与流媒体，内置一个能从网页嗅探视频直链的浏览器，并运行 hikerView 兼容的小程序，从而浏览第三方视频源。

**问：支持哪些平台？**

答：macOS 14 Sonoma 及以上（针对 Apple Silicon 优化，支持 Intel），以及 iOS / iPadOS 16 及以上。

**问：它使用了 ffmpeg 或其他外部二进制吗？**

答：没有。播放与重封装内核完全基于 Apple 的 AVFoundation（AVPlayer）构建。这让应用保持轻量并符合 App Store 规范。

**问：它能播放哪些视频格式？**

答：任何 AVPlayer 原生解码的格式——HLS（`m3u8`）、MP4、MOV、M4V，以及其他容器。对于 HLS，nPlyr 还可以在应用内下载并重封装为 MP4。

**问：嗅探器与小程序有何不同？**

答：嗅探器捕获网页实际请求的媒体链接。小程序则是一条了解某源结构与 API 的规则，因此它能够浏览分类、搜索并解析可播放链接——对于嗅探器搞不定的站点更可靠。

**问：小程序安全吗？它们来自哪里？**

答：小程序是社区提供的 hikerView 兼容规则，运行在沙盒化的 JavaScript 引擎内。它们并非由 nPlyr 编写。具体支持哪些行为，请参阅[兼容性](/zh-CN/guide/miniapp-compatibility)，并且只安装你信任的源。

**问：我的数据私密吗？**

答：你的媒体库、历史与书签都留在你的设备上（且仅通过你自己的账号同步）。浏览器是一个标准的 WKWebView，没有额外的追踪器。没有遥测。参见[隐私](/zh-CN/guide/privacy)。

**问：免费版功能齐全吗？**

答：核心播放器、嗅探器、下载与媒体库均可完全使用。免费层级限制导入的小程序数量；一次性解锁会移除该限制。

**问：界面提供哪些语言？**

答：25 种语言，可在设置中实时切换，无需重启。
