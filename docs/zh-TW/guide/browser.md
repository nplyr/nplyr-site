# 瀏覽器與嗅探器

nPlyr 內建一個基於 `WKWebView` 的真正的**多分頁瀏覽器**，並帶有**媒體嗅探器**。當你遇到一個不主動提供直鏈的頁面時，它就是用來擷取直鏈的工具。

## 瀏覽器

這是一個 Chrome 風格的分頁瀏覽器：

- **分頁**——新建 / 關閉 / 切換 / 重新排序；將分頁拖出可成為獨立視窗（macOS）。
- **導覽**——上一頁、下一頁、重新載入，以及帶自動完成的網址列。
- **鍵盤快捷鍵**——`⌘T` 新建分頁、`⌘R` 重新載入、`⌘[` / `⌘]` 上一頁 / 下一頁、`⌘L` 聚焦網址列。
- **拖放**——將 URL 或文字拖入視窗即可開啟。
- **彈出視窗**——`target="_blank"` 與 `window.open` 會在新分頁中開啟，而不是被攔截。
- **對話框**——JS 的 `alert` / `confirm` / `prompt` 以原生方式呈現。
- **下載**——被攔截的下載連結會在應用程式內**下載**分頁（`nplyr://downloads`）中開啟。

## 嗅探器的運作原理

頁面載入時，nPlyr 會注入一個腳本，攔截：

- `fetch` 與 `XMLHttpRequest`，
- `video.src` 與 `HTMLMediaElement` 播放，
- `MediaSource` / `SourceBuffer.appendBuffer`。

它還會透過 `WKNavigationDelegate` 監視導覽，以捕獲服務端媒體重新導向。任何看起來像媒體檔案的內容——**m3u8 / mp4 / flv / ts**——都會連同其**請求標頭**（referer、user-agent、cookie、auth）一起被收集到結果抽屜中。

在抽屜中你可以：

- 立即在[播放器](/zh-TW/guide/player)中**播放**該連結。
- 透過[下載](/zh-TW/guide/downloads)將其**下載**（保留請求標頭）。
- **複製** URL 與請求標頭，以便在其他地方使用。

> 嗅探器只擷取頁面實際請求的連結。使用專有播放器或重度 DRM 包裹影片串流的網站可能不會暴露乾淨的直鏈——對於這類來源，一個了解該來源 API 的[小程式](/zh-TW/guide/miniapps)是更可靠的路徑。

## 已知限制

以下項目是有意降低優先級，可能在後續版本中提供：

- 頁內右鍵選單項目（「在新分頁開啟連結」、「下載連結」）——macOS 的 `WKUIDelegate` 右鍵選單鉤子是 iOS 專屬的；nPlyr 目前依賴分頁列與工具列。
- 頁內**尋找**（`⌘F`）——WebKit API 存在，但 UI 尚未接好。
- **列印**（`⌘P`）——WebKit 支援，但尚無選單項目。
- `⌘W` 在多個分頁開啟時會關閉整個視窗；按分頁關閉正在規劃中。
- 全面重啟應用程式後，已開啟的分頁與歷史**不會**恢復。

## 隱私

該瀏覽器是一個標準的 `WKWebView`。它不會注入自身的追蹤器。Cookie 與本機儲存都留在應用程式的容器中。完整說明請參閱[隱私](/zh-TW/guide/privacy)。
