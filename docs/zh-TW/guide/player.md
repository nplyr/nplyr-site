# 播放器

nPlyr 的播放器是一套由 `AVPlayer` 驅動、macOS 與 iOS 共用的核心。本頁介紹日常控制項與平台專屬手勢。

## 開啟內容

從主畫面你可以：

- **開啟檔案**——將本機影片拖入視窗，或使用檔案選擇器。
- **開啟 URL**——將直鏈（`.mp4`、`.m3u8`、`.flv`、`.ts` 等）貼到 URL 輸入框。
- **從嗅探器開啟**——將擷取的連結從[瀏覽器](/zh-TW/guide/browser)抽屜直接傳送給播放器。
- **從小程式開啟**——點擊可播放的項目，nPlyr 會透過[規則引擎](/zh-TW/guide/miniapps)解析它。

## 常用控制項（雙平台通用）

| 控制項 | 作用 |
|---|---|
| 播放 / 暫停 | 空白鍵（macOS）或輕點影片中心（iOS） |
| 進度 | 拖動進度條，或使用下方平台手勢 |
| 音量 | 系統 / 螢幕音量 |
| 倍速 | 透過倍速按鈕在 0.5×–3× 之間調整 |
| 音軌 | 當來源包含多音軌時可選擇 |
| 字幕 | 載入外部 `.srt` / `.vtt`，或使用內嵌音軌 |
| 畫中畫 | 將影片彈出為懸浮的畫中畫視窗 |
| AirPlay | 將影片傳送到 Apple TV 或 AirPlay 喇叭 |
| DLNA（macOS） | 投放到區域網路中的 DLNA 裝置 |

## macOS 手勢與快捷鍵

### 觸控板

- **橫向滑動**拖動時間軸。拖動時**預覽**新位置；當你抬起手指（或停頓 250 毫秒）時才真正跳轉，因此誤滑絕不會讓影片亂跳。
- **縱向滑動**根據起始位置調整**亮度**或**音量**：影片**左半側**控制亮度，**右半側**控制音量。第一次滑動會鎖定軸向，二者互不干擾。
- **滾輪**懸停在進度條上時可微調位置（每格 ±5%）。

### 亮度

macOS 不提供公開 API 來調暗其他應用程式的影片，因此 nPlyr 在影片與控制項之間疊加一層調暗層。這只是視覺上的處理——底層畫面本身並未改變。

### 鍵盤快捷鍵

快捷鍵僅按**修飾鍵**（`⌘`、`⌥`、`⌃`、`⇧`）匹配——方向鍵與小鍵盤不參與匹配，因此方向鍵綁定始終可靠。在文字框（URL 列、搜尋框等）中輸入時，單鍵快捷鍵會被抑制。

如果某個快捷鍵突然失效，請參閱[疑難排解](/zh-TW/guide/troubleshooting)。

## iOS 手勢

- **雙擊**將螢幕分為三個區域：輕點**左三分之一**後退 10 秒，**右三分之一**前進 10 秒，**中間**播放 / 暫停（並在點擊處顯示漣漪）。
- **長按（0.5 秒）**暫時以 **2.0×** 播放；鬆開後恢復普通速度。
- 邊緣**死區**（約 30 pt，或短邊的 10%）被忽略，因此從螢幕邊緣開始滑動不會誤觸手勢。該死區僅在全螢幕時生效。

## 進階播放

### 多線路影片 JSON

某些規則會回傳一個結構化 JSON，描述多條影片線路（不同解析度或 CDN）、字幕、歌詞與音訊 URL。nPlyr 將其解析為一個**線路切換器**，讓你在不丟失進度的情況下切換線路。

### 續播與換源

- nPlyr 會記住你停在哪裡，並在下次提供**續播**選項。
- 在播放中途切換來源時，交換瞬間會**凍結最後一幀**，以免螢幕閃黑。
- 在項目就緒之前發出的跳轉會被**排入佇列**，並在播放可以開始的瞬間立即套用——因此你永遠不會在不知情的情況下從頭重播。

### 邊下邊播

你可以在檔案仍在下載時就開始觀看。請參閱[下載與媒體庫](/zh-TW/guide/downloads)。
