# 隱私選擇

nPlyr 是一款本機優先的應用程式。由於你的資料留在你的裝置上，我們不會收集、出售或共享任何個人資訊。

## 我們本機儲存的資料

nPlyr 將所有資料本機儲存在你的裝置上：

- 觀看歷程、書籤與下載內容
- 應用程式偏好與主題
- 小程式變數（僅在本機儲存中，且僅來自你匯入的規則）
- 偵錯日誌（若啟用）

這些資料都不會被應用程式本身上傳到任何伺服器。

## 網路由使用者主導

nPlyr 僅在串流媒體、下載、瀏覽或執行你選擇的某個小程式時使用網路。沒有雲端 AI 功能，也沒有帳號，因此沒有需要選擇加入或退出的事項——應用程式根本不會把你的資料傳送給我們。

## 你的權利

由於 nPlyr 不在我們的伺服器上收集或儲存個人資料，也就沒有可供我們存取、刪除或轉移的個人資料。你所有的資料都可以在應用程式內直接管理，或透過移除應用程式的容器資料夾來管理：

```bash
rm -rf ~/Library/Containers/com.w3cub.nPlyr
```

## 不出售

nPlyr 不出售任何個人資訊。我們不使用任何第三方的分析、廣告或追蹤服務。

## 聯絡
