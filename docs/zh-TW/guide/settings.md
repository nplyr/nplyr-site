# 設定

nPlyr 的設定視窗按標籤頁組織。本頁帶你了解大多數人最先更改的若干項。

## 外觀與語言

### 主題

nPlyr 內建多個主題，每個都以一個標誌性的強調色為基調。切換主題時，整個介面——包括每一個開啟的視窗——都會立即更新。你也可以自動**跟隨系統外觀**（淺色 / 深色）。

### 語言

介面已在地化為 **25 種語言**。更改語言會在所有已開啟視窗與選單列上立即生效——無需重新啟動。（這一即時切換是透過在語言變化時重建每個視窗的視圖來實現的。）

## 一般

- **瀏覽器 user-agent**——選擇 *自動*、*行動裝置*、*桌面端（PC）*，或貼上一段**自訂** UA。該 UA 由[嗅探器](/zh-TW/guide/browser)以及播放/解析在需要時採用。規則也可以指定自己的 UA；只有當選擇跟隨規則的值時，齒輪設定才會覆寫它。
- **檔案關聯**——讓 nPlyr 當你在 Finder 中雙擊本機影音檔案（`.mp4`、`.mkv`、`.mov`、`.m4v`、`.webm`、`.flv`、`.mka` 等）時開啟它們。

## 下載

- 已下載媒體的預設儲存位置。
- 是否提供**邊下邊播**。
- 清晰度預設值，以及是否自動下載字幕。

## 播放器

- 預設播放速度。
- 手勢偏好（觸控板 / 觸控靈敏度）。
- 畫中畫與 AirPlay 預設值。

## 去廣告

訂閱 Chrome 相容的過濾清單。nPlyr 會在瀏覽器中以及播放期間過濾請求。去廣告與邊下邊播互斥。

## 小程式

管理已匯入的小程式與規則來源：新增、編輯、重新排列與刪除。**免費層級**會限制小程式的數量；解鎖後移除該限制，以一次性購買形式儲存。請參閱[小程式](/zh-TW/guide/miniapps)。
