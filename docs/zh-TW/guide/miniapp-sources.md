# 小程式來源

本頁屬於**小程式**指南章節——即 nPlyr 可以匯入的社群小程式與規則來源目錄。nPlyr **不**隨附固定的影片來源清單；相反，來源由你自行提供，應用程式內的管理器負責匯入。

## 來源來自哪裡

- **hikerView 生態。** nPlyr 與 Android 應用程式所用的同一批分享文字和 JSON 相容，因此現有社群規則可直接匯入。
- **雲端分享。** nPlyr 支援雲端後端 **TextDB**（雲2）、`cmd.im`（302 重新導向，雲5）與 **pasteme**（雲6），因此託管在那裡的規則可以一步訂閱。
- **你自己的。** 編寫或改編一條規則並匯入——請先參閱[小程式概覽](/zh-TW/guide/miniapps)與[相容性](/zh-TW/guide/miniapp-compatibility)邊界。

## 新增來源

1. 在 nPlyr 中打開**小程式**（macOS 上是管理器視窗，iOS 上是一個頁面）。
2. 選擇**新增**，貼上分享文字 / JSON，或選擇一個雲端來源進行訂閱。
3. 該程式會出現在首頁頂列——拖拽以重新排列。

免費層級限制你一次可保留的匯入程式數量；一次性解鎖會移除該限制。

## 相容性是關鍵

並非每一條 Android 規則都在 nPlyr 上完全一致地執行。nPlyr 的引擎是 **JavaScriptCore**，而非 Java/Rhino，並且只模擬了經過篩選的 Java API 子集。在依賴某個來源之前，請查閱[相容性](/zh-TW/guide/miniapp-compatibility)頁面，並回報任何失敗的規則（附上規則名稱及其失敗的步驟）。

> 你在此瀏覽的目錄由社群維護。nPlyr 並非第三方小程式的作者，也不為其內容背書——只安裝你信任的來源。
