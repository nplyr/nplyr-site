# 權限

nPlyr 刻意**精簡權限**。因為它是一個媒體播放器（而非剪貼簿或錄影工具），它**不**請求輔助使用或螢幕錄製權限。唯一可能出現的權限，是任何需要網路與檔案的應用程式都需要的那些標準權限。

## 網路存取

串流媒體、嗅探與小程式來源都需要出站網路存取。在 macOS 上，App Store 沙盒預設允許——**不會有任何提示**，也無需手動授權。

## 檔案與資料夾

- **開啟本機檔案**使用標準的 macOS 開啟面板，因此由你自己挑選檔案；不需要任何整體資料夾存取權限。
- **儲存下載**會寫入你的**下載**資料夾（或你選擇的資料夾）。首次下載時，macOS 可能會彈出沙盒提示以確認位置。授權一次，nPlyr 就會記住該選擇。

如果之後移動了 nPlyr 的資料或撤銷了存取，你可以在**系統設定 → 隱私與安全性 → 檔案與資料夾**中重新授權。

## 通知（選用）

下載完成時，nPlyr 可能會顯示一個本機通知。這是選用的，可在**系統設定 → 通知 → nPlyr** 中關閉。

## nPlyr 不請求什麼

| 權限 | 是否需要 | 原因 |
|---|---|---|
| 輔助使用 | 否 | 鍵盤快捷鍵使用應用程式內事件監視器，而非全域輔助使用控制。 |
| 螢幕錄製 | 否 | nPlyr 播放並擷取*網路*媒體；它從不錄製你的螢幕。 |
| 完全磁碟存取 | 否 | 所有檔案存取都經由開啟/儲存面板或下載資料夾進行。 |
| 相機 / 麥克風 | 否 | nPlyr 是一個觀看工具；它不擷取輸入裝置。 |

如果你看到此處未列出的權限提示，幾乎可以肯定來自某個小程式或瀏覽器存取的特定網站——而非核心應用程式。如果看起來有什麼不對，請參閱[疑難排解](/zh-TW/guide/troubleshooting)。
