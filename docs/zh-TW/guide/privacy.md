# 隱私政策

nPlyr 是一款面向 macOS 與 iOS 的原生影片播放器。你的隱私是我們的首要任務。

## 本機優先設計

- 你的觀看歷程、書籤與下載內容**完全儲存在你自己的裝置上**。
- 應用程式**不需要帳號，也不需要註冊**。
- **沒有遙測**——nPlyr 不會將使用資料回傳。
- 一旦媒體已在你的裝置上，核心播放與下載功能可完全離線工作。

## 網路使用由使用者主導

nPlyr 只在*你*要求時才使用網路：

- 串流播放或下載你開啟或擷取的影片。
- 使用內建嗅探器瀏覽。
- 執行你匯入的小程式 / 規則來源。

我們不營運接收你的媒體、歷程或小程序變數的伺服器。

## 瀏覽器

內建瀏覽器是一個標準的 `WKWebView`。它不會注入自身的追蹤器。Cookie 與本機儲存都留在應用程式的容器中，與其他任何瀏覽器一樣。

## 小程式資料

小程式是社群提供的規則，執行在沙盒化的 JavaScript 引擎中。規則儲存的任何變數（`setItem` / `getItem`）都保存在你裝置上的應用程式本機儲存中。nPlyr 不會讀取或傳輸它們。

## 偵錯日誌

如果你啟用了偵錯日誌，日誌會被寫入本機，並且只有在*你*選擇匯出它們以回報問題時才會被分享。

## 你的選擇

- 隨時刪除單一歷程 / 書籤 / 下載項目。
- 從**設定 → 進階 → 重設**重置所有本機資料。
- 從**小程式**管理器中移除一個小程式及其儲存的變數。

nPlyr 的設計預設就是私密的——沒有什麼需要「退出」。
