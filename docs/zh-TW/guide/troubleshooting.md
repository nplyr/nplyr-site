# 疑難排解

本頁彙整 nPlyr 在 macOS 與 iOS 上的常見問題及解決方法。

## 應用程式無法啟動或啟動即崩潰

1. 確認你的系統滿足最低要求（macOS 14 Sonoma 及以上，或 iOS / iPadOS 16 及以上）。
2. 退出並重新啟動應用程式。
3. 如果你側載了開發版本，請確認描述檔仍然有效。

## 影片無法播放（一直轉圈或報錯）

- 確認連結是一個**直鏈**媒體 URL（`mp4`、`m3u8`、`flv`、`ts` 等），而不是一個頁面。使用[瀏覽器與嗅探器](/zh-TW/guide/browser)擷取真正的連結。
- 某些網站需要特定的**請求標頭**（referer、cookie、auth）。透過嗅探器擷取連結會自動保留這些請求標頭。
- `TS → MP4` 透傳需要格式提示；如果某個 TS 來源失敗，請嘗試從線路切換器選擇另一條線路。
- 來自來源的 `403` 通常是短暫的網站側限流；請等待後重試，而不是盲目更改請求標頭。

## 嗅探器在某個網站上什麼也擷取不到

- 該頁面可能透過專有播放器或 DRM 載入影片，從不請求普通媒體檔案。此時，與該來源 API 通訊的[小程式](/zh-TW/guide/miniapps)才是正確的工具。
- 嘗試重新載入頁面，或在[設定](/zh-TW/guide/settings)中將**瀏覽器 user-agent**切換到行動裝置 / 桌面端。

## 某個鍵盤快捷鍵不起作用

- 快捷鍵僅按修飾鍵匹配（`⌘`、`⌥`、`⌃`、`⇧`）；方向鍵與小鍵盤不屬於綁定的一部分。
- 當你在文字框（URL 列、搜尋框）中輸入時，單鍵快捷鍵會被有意抑制，以免與你的輸入衝突。
- 如果某個綁定依然感覺失效，請檢查它是否在**系統設定 → 鍵盤 → 鍵盤快捷鍵**中被系統或應用程式快捷鍵遮蔽。

## 下載停滯或失敗

- 單一片段失敗會將下載標記為 `.failed`；可從標記檔案續傳。
- 如果某個網域反覆回傳 `404`，nPlyr 會在本次工作階段中將其列入黑名單，且不會靜默改道——請選擇另一個來源。
- 重新封裝失敗會保留原始 `.ts` 並標記為 `completed`，因此你的資料不會遺失。

## 某個小程式的行為與 Android 上不同

原始引擎是 Android/Java（Rhino）。nPlyr 在 JavaScriptCore 上執行規則，並為規則所依賴的部分實作了一個 **Rhino→Java 相容層**。部分 Java 特有的行為是有意不支援的。請查閱[相容性](/zh-TW/guide/miniapp-compatibility)頁面；如果某條具體規則失敗，請回報規則名稱。

## 重置 nPlyr

你可以從**設定 → 進階 → 重設**重置應用程式的本機資料（媒體庫、書籤、小程式變數）。這不會影響你已購買的解鎖。
