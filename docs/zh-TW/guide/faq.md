# 常見問題

**問：nPlyr 是什麼？**

答：nPlyr 是一款面向 macOS 與 iOS/iPadOS 的原生影片播放器。它可以播放本機檔案與串流媒體，內建一個能從網頁嗅探影片直鏈的瀏覽器，並執行 hikerView 相容的小程式，從而瀏覽第三方影片來源。

**問：支援哪些平台？**

答：macOS 14 Sonoma 及以上（針對 Apple Silicon 最佳化，支援 Intel），以及 iOS / iPadOS 16 及以上。

**問：它使用了 ffmpeg 或其他外部二進位嗎？**

答：沒有。播放與重新封裝核心完全基於 Apple 的 AVFoundation（AVPlayer）建構。這讓應用程式保持輕量並符合 App Store 規範。

**問：它能播放哪些影片格式？**

答：任何 AVPlayer 原生解碼的格式——HLS（`m3u8`）、MP4、MOV、M4V，以及其他容器。對於 HLS，nPlyr 還可以在應用程式內下載並重新封裝為 MP4。

**問：嗅探器與小程式有何不同？**

答：嗅探器擷取網頁實際請求的媒體連結。小程式則是一條了解某來源結構與 API 的規則，因此它能夠瀏覽分類、搜尋並解析可播放連結——對於嗅探器搞不定的網站更可靠。

**問：小程式安全嗎？它們來自哪裡？**

答：小程式是社群提供的 hikerView 相容規則，執行在沙盒化的 JavaScript 引擎內。它們並非由 nPlyr 編寫。具體支援哪些行為，請參閱[相容性](/zh-TW/guide/miniapp-compatibility)，並且只安裝你信任的來源。

**問：我的資料私密嗎？**

答：你的媒體庫、歷程與書籤都留在你的裝置上（且僅透過你自己的帳號同步）。瀏覽器是一個標準的 WKWebView，沒有額外的追蹤器。沒有遙測。請參閱[隱私](/zh-TW/guide/privacy)。

**問：免費版功能齊全嗎？**

答：核心播放器、嗅探器、下載與媒體庫均可完全使用。免費層級限制匯入的小程式數量；一次性解鎖會移除該限制。

**問：介面提供哪些語言？**

答：25 種語言，可在設定中即時切換，無需重新啟動。
